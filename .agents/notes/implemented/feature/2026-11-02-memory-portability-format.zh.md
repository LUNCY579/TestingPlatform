# Agent Note: 获授权的记忆迁移与嵌入空间迁移

Status: implemented

[English](2026-11-02-memory-portability-format.md) | 中文

## 问题

显式记忆是原生存储中的权威记录，因此更换嵌入提供方、模型、端点、权重版本、归一化方式或维度时，无法像重建源索引恢复片段那样恢复它们。面对这种变更，操作者过去只能手工编辑存储内容。手工编辑会带来此处最关键的三种失败：复活操作者已经遗忘的事实、让过期或被替代的记录重新进入检索、以及冒充接收宿主从未授予的所有权记录。导出还必须能在中断后恢复，因为写了一半的记录集合比没有导出更糟。

## 决策

[迁移格式](../../../../packages/retrieval/retrieval/src/portability.ts)与其[写入次序](../../../../packages/retrieval/retrieval/src/portability-ops.ts)把已提交的记忆表示为一个带版本的信封：格式版本、导出时间、源嵌入空间，以及每条记录按声明固定顺序排列的全部存储字段，包括所有权键、作用域、来源归因、版本、替代关系、创建与更新时间、有效期、内容摘要和空间键。新增记录字段而不在格式中作出决定会导致编译失败。读写使用同一个 `MEMORY_EXPORT_VERSION`，读取端遇到其他版本直接拒绝而不猜测。

解码依据引擎自身写入的事实校验信封：文本必须哈希为记录的摘要，引擎从不写入的所有权组合被拒绝，`pending` 行被拒绝，因为只有其所属存储能解析未完成的替代。导出会先为该调用者完成待处理替代，因此导出不会携带写了一半的生命周期。所有权原样传递；接收身份无权写入的记录会被拒绝并按 ID 报告。

遗忘操作在删除之前把记录 ID 与内容摘要追加到遗忘账本，并在账本不可写时拒绝删除。导入会读取该账本，并拒绝账本已知遗忘的 ID，直到操作者主动删除该条目。过期与被替代记录保持原状态，因此导入不会让已失效事实重新可检索。

导入把接受的文本重新嵌入当前挂载存储的空间，而不是搬运向量；按目标存储路径命名的写前日志暂存本批记录；校验每条记录逐字节回读一致且带有目标空间的向量，并用一条生效记录验证可检索、一条失效记录验证不可检索，之后才发布。写入或校验失败会精确删除本批暂存 ID，并在无法证明删除成功时保留日志，使该存储的下一次导入在规划前先完成清理。源存储从不以写入方式打开，其备份因此保持有效。

两个由操作者执行的命令通过现有身份解析器访问这条路径，且仅在 `retrieval.config.portabilityEnabled` 为真时注册。所有文件都位于操作者指定的绝对 `portabilityDir` 之下，经路径回溯或文件系统链接指向该目录之外的名称会在任何读写之前被拒绝，整个子系统默认关闭。

## 考虑过的替代方案

**复制已存储的向量：**向量只在生成它的那个空间中有意义，跨模型、维度或归一化变更复制向量会静默混合空间。重新嵌入把已存储文本视为权威，并依靠每次导入都执行的同一套校验证明目标空间。

**把导出导入做成模型工具：**这两个调用都会搬运整批个人事实，应当是一次明确的人工决定，而不是可以从提示词触达的操作。此外，该能力默认关闭时仍会给每个请求增加 schema。

**导入时改写所有权以便任意存储接受任意导出：**受保护的是记录文本加上它的作用域。改写会让伪造的信封把他人的事实声称为自己的，因此准入选择拒绝而不是适配。

**登记所有已创建的 ID，而不仅是被遗忘的：**随每条记忆增长的 ID 账本会把保留变成第二套权威，却没有有限用途。只有负向记录会改变后续行为，因此账本只记录删除。

**先删除再写账本：**两者之间发生中断会让该 ID 既不在存储中也不在账本中，之后导入较早的导出就会静默复活已被遗忘的事实。先写账本的失败方向是安全的：多出一次操作者可以检查的拒绝。

**加载时发现嵌入空间变化就自动迁移：**那会在应用启动这一副作用中改写权威记录，既没有选定目标存储，也没有操作者确认。服务改为拒绝不匹配的空间，把迁移留给一条命令。

## 后果

可迁移换来的是一条受支持的嵌入空间迁移路径、按存储隔离的中断安全暂存协议，以及每条被拒记录一个可见原因。代价是与存储一同备份的持久文件多出两类，而且保证范围按目录划分：遗忘账本位于当前 `portabilityDir` 之下，因此删除之前制作的存储备份，或指向另一个目录的导入，仍可能重新引入该事实。导出是明文记忆文本，所以 `portabilityDir` 必须位于仓库之外，文件由操作者自行保护。迁移规模受 `maxPortabilityRecords` 限制，并对接受的文本执行一次重新嵌入。

验证分布如下：[portability.spec.ts](../../../../packages/retrieval/retrieval/tests/portability.spec.ts) 覆盖格式、路径和账本规则；[portability-ops.spec.ts](../../../../packages/retrieval/retrieval/tests/portability-ops.spec.ts) 覆盖往返、授权、取消、故障注入回滚和中断日志清理；[命令测试](../../../../packages/retrieval/retrieval-tools/tests/portability.spec.ts)在原生存储上覆盖注册、参数解析、路径逃逸以及来自旧空间的导入。跨机恢复与多操作者导入尚未验证。存储权威性由[权威本地检索](../architecture/2026-11-01-authoritative-local-retrieval.zh.md)记录。
